# Pratap Labs — Optimized Website

Static website for prataplabs.com.

## Changes
- Removed the Data Readiness Check and unused spreadsheet parser dependency.

## Deploy
Upload `index.html` and `CNAME` to the root of the website repository. No build step or Excel library is needed.

## Review before launch
Verify all biography credentials, business representations, demo behavior and contact details. Test the page on desktop and mobile browsers. The synthetic demo does not represent client results.
